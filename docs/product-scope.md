# ClipPilot 产品边界

## 定位

ClipPilot 是一个本地优先的剪贴板与提示词工作区。它不试图替代完整的剪贴板历史工具，而是把"值得重复使用的文本"整理成可搜索、可编辑、可复制的个人素材库。

## MVP 已完成

- 普通片段 / 提示词两种类型
- 本地保存、搜索、收藏、编辑、删除
- 读取系统剪贴板并保存
- 复制片段到系统剪贴板
- 去首尾空格、格式化 JSON、大小写转换
- Windows 与 Android 共用一套 React 页面
- debug 构建显示 `DEV_MODE`，release 构建隐藏

## 有意不做

以下能力先不进入 MVP：

- 全局快捷键和系统托盘
- 后台持续监听系统剪贴板
- 云同步、登录和团队协作
- 内置 LLM 账号体系或后端代理
- 富文本、图片剪贴板和附件管理

这些功能会引入平台权限、后台生命周期、隐私和服务端成本，不符合首版短周期验证目标。

## 下一阶段候选

按优先级排序：

1. 全局快捷键打开快速搜索窗口（桌面端）
2. 可配置的 LLM provider，用于润色/总结/翻译，并明确 key 只保存在本机
3. Tauri Store 或 SQLite 替代 localStorage，支持更大规模历史记录
4. 剪贴板监听开关与隐私过滤（密码、token、银行卡号不入库）
5. Android 分享面板入口，将外部文本直接保存到 ClipPilot

每次只推进一个候选项，先保持本地优先和无后端的维护优势。
